- **Standard:** `english-code-standard`

---

## 1. Overview & Context

ArcPaper v1.7.0 completed Phase 2 multi-monitor support (PerMonitor, Clone, and Span display modes with shared hardware decoding). However, auto-pause detection in v1.7.0 relies on polling (`EnumWindows` executed approximately every 1000 ms by `ArcPaper-AutoPauseMonitor`), and lacks power or session awareness (battery saver, workstation lock, remote desktop, display sleep, or exclusive fullscreen games).

Before implementing Phase 3 features in v1.8.0, baseline measurements on v1.7.0 establish ground truth for CPU utilization, RAM consumption, pause latency, and runtime stability.

## 5. Developer Measurement Execution Guide

### Prerequisites
1. Build the release binary on commit `c0be906`:
   ```powershell
   cargo build --release
   ```
2. Start `arc_paper.exe`:
   ```powershell
   .\target\release\arc_paper.exe
   ```

### 5.1 Scenario 1: Active 1-Monitor Resource Baseline
Run `measure_resource.ps1` for 10 minutes (600 seconds) with primary monitor active:
```powershell
.\scripts\measure_resource.ps1 -ProcessName arc_paper -DurationSeconds 600 -IntervalSeconds 1 -OutputFile docs\baselines\active_1mon.csv
```

### 5.2 Scenario 2: Active 2-Monitor Resource Baseline (spacedesk)
1. Connect smartphone client via spacedesk.
2. Confirm Windows detects Display 2 in Extended Desktop mode.
3. Verify `arc_paper` renders across both monitors.
4. Run measurement for 10 minutes:
```powershell
.\scripts\measure_resource.ps1 -ProcessName arc_paper -DurationSeconds 600 -IntervalSeconds 1 -OutputFile docs\baselines\active_2mon_spacedesk.csv
```

### 5.3 Scenario 3: Global Paused State Resource Baseline
1. Cover both monitors with maximized windows (or toggle pause from system tray).
2. Allow 10 seconds for hibernation trim (`IDXGIDevice3::Trim`).
3. Run measurement for 10 minutes:
```powershell
.\scripts\measure_resource.ps1 -ProcessName arc_paper -DurationSeconds 600 -IntervalSeconds 1 -OutputFile docs\baselines\paused_state.csv
```

### 5.4 Scenario 4: Pause Latency Benchmark
Parse pause transitions from `app.log`:
```powershell
.\scripts\measure_pause_latency.ps1 -LogPath "$env:APPDATA\ArcPaper\app.log" -SampleCount 100
```
*Note: To verify script calculations with synthetic distributions, run:*
```powershell
.\scripts\measure_pause_latency.ps1 -Synthetic -SimulatePolling -SampleCount 100
```

### 5.5 Scenario 5: 1-Hour Stability Soak Test
Execute the 1-hour soak test monitoring stability and memory drift:
```powershell
.\scripts\soak_1h.ps1 -ProcessName arc_paper -DurationMinutes 60 -IntervalSeconds 60 -OutputFile docs\baselines\soak_1h_result.csv
```
